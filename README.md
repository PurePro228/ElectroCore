# ElectroCore

Симулятор электронных схем в браузере. Собирайте цепи на рабочем столе, соединяйте
элементы проводами и наблюдайте напряжение, ток и мощность в реальном времени —
расчёт ведётся по законам электротехники, а не по приближённым формулам.

Открывается двойным щелчком по `index.html`: сборка не требуется, зависимостей нет.

## Возможности

**Рабочий стол**
- Перетаскивание элементов по сетке, автоматическая ортогональная разводка проводов
- Поворот, дублирование, выделение рамкой, отмена и повтор действий
- Масштаб колесом мыши и щипком, панорама средней кнопкой или пальцем
- Анимация тока по проводам, окраска цепей по потенциалу
- Сохранение в браузере, экспорт и импорт схемы в JSON

**28 компонентов**

| Группа | Элементы |
|---|---|
| Пассивные | резистор (с цветовой маркировкой), конденсатор, электролит, катушка, потенциометр, лампа накаливания, предохранитель |
| Источники | земля, батарея, генератор сигналов (синус, меандр, треугольник, пила, импульсы), источник тока |
| Коммутация | выключатель, кнопка, переключатель, реле |
| Полупроводники | диод, стабилитрон, светодиод, транзисторы NPN и PNP, MOSFET N- и P-канала, операционный усилитель |
| Измерения | вольтметр, амперметр, ваттметр, щуп осциллографа, узел |

**Измерения**
- Напряжение, ток и мощность у каждого элемента прямо на схеме
- Приборы с цифровыми экранами: вольтметр (10 МΩ), амперметр (шунт 1 мΩ), ваттметр с токовыми клеммами и клеммами напряжения
- Осциллограф на шесть каналов: размах, среднее, действующее значение, частота

**Телефон и планшет**
- Палитра и свойства открываются выдвижными панелями снизу
- Нижняя панель с основными действиями, крупные области касания
- Щипок для масштаба, один палец для панорамы

## Физическая модель

Схема решается модифицированным методом узловых потенциалов (МУП). На каждом шаге
по времени составляется система `A·x = b`, где неизвестные — потенциалы узлов и токи
ветвей источников напряжения; система решается LU-разложением с выбором главного элемента.

- **Нелинейные элементы** линеаризуются методом Ньютона–Рафсона с ограничением шага
  на p-n переходах (алгоритм `pnjlim` из SPICE) и утечками `gmin` для сходимости.
- **Диоды, светодиоды, стабилитроны** — уравнение Шокли `I = Is·(exp(U/nUт) − 1)`
  с отдельной ветвью обратного пробоя.
- **Биполярные транзисторы** — модель Эберса–Молла с прямым и обратным коэффициентами передачи.
- **Полевые транзисторы** — квадратичная модель с модуляцией длины канала.
- **Реактивные элементы** интегрируются по методу трапеций: конденсатор заменяется
  проводимостью `2C/h` с источником тока, катушка — проводимостью `h/2L`.
- **Лампа накаливания** учитывает нагрев нити: сопротивление растёт примерно в 10 раз,
  яркость меняется с постоянной времени 0,12 с.
- **Шаг интегрирования** подбирается автоматически по частоте источников и резонансу LC-контуров.

## Проверка

```
node test/engine.test.js
```

41 проверка сверяет расчёт с аналитическими формулами: закон Ома, законы Кирхгофа,
постоянная времени RC, резонанс LC, прямое падение на диоде, коэффициент передачи
транзистора, усиление ОУ, действующее значение и мощность на переменном токе,
ёмкостное сопротивление, показания приборов.

## Структура

```
index.html          разметка интерфейса
css/style.css       оформление, адаптация под телефон
js/util.js          формат величин (4.7к, 10мк), разбор ввода, математика
js/solver.js        LU-разложение, сборка матрицы МУП, функции p-n перехода
js/components.js    библиотека элементов: модели и отрисовка
js/circuit.js       узлы схемы, транзиентный анализ, токи в проводах
js/render.js        рисование рабочего стола на canvas
js/scope.js         осциллограф
js/examples.js      готовые схемы
js/app.js           интерфейс, ввод, цикл расчёта
test/engine.test.js проверка физики
```
